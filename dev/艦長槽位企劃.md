# 艦長模式：槽位制度與新戰艦（規劃中，2026-11-22）

新戰艦（戰艦建模的 6 艘）先加入艦長模式。同時把艦長模式的「5 個固定槽＋模組」改成「依艦種、等級開放的槽位」。

## 一、已決定（2026-11-22）

| 問題 | 決定 |
|---|---|
| 適用範圍 | **全部換成新制度**：突擊艦、重砲艦、支援艦、電戰艦、匿蹤艦也改；舊存檔的模組換算成新槽位 |
| 槽位種類 | 主砲槽、副砲槽、防空槽、艦載機槽、輔助槽 |
| 槽位可以裝什麼 | **只照規則，不能再往下跨**（見下表） |
| 飛彈 | 飛彈艙算副砲級，裝在副砲槽 |
| 輔助裝備 | 實體裝甲、能量護盾、超頻引擎；**三種都分大、中、小** |
| 多門主砲 | **一起朝準心射**：每門在自己的射界內轉向準心，按開火時射界內的一起打 |
| Mk 等級 | **跟著裝備走**：每件裝備有自己的 Mk，上限仍是「船等級」與「研發」取低的 |
| 新戰艦 | **每艘都是新艦種**，各有數值、槽位表、技能 |
| 槽位位置 | 每艘船的槽位位置固定，在**戰艦組裝編輯器**裡編輯 |
| 放進遊戲 | 編輯器要有明確的操作，由你決定哪些設計放進遊戲、每個等級長什麼樣子 |

### 槽位能裝的東西

| 槽位 | 武器 | 輔助裝備 |
|---|---|---|
| 主砲槽 | 主砲、副砲級（副砲、飛彈艙） | 大型 |
| 副砲槽 | 副砲級（副砲、飛彈艙） | 中型 |
| 防空槽 | 防空砲 | 小型 |
| 艦載機槽 | 艦載機（只能放艦載機） | — |
| 輔助槽 | — | 大、中、小都可以 |

飛彈艙算副砲級，所以主砲槽也能裝（2026-11-22 確認）。

## 二、做法

### 1. 艦種＝每個等級一份設計

- 在戰艦組裝編輯器裡，每個艦種有 **Lv1～Lv5 各一份設計**，也就是組好的船加上槽位標記。等級越高，船可以長得越大、越完整。
- **槽位標記**是放在船上的一個小框，帶有種類（主砲／副砲／防空／艦載機／輔助）、位置、朝向和射界。
  - 輔助槽通常在船體內部，只是位置記號。
- **槽位表在編輯器裡編**：每個艦種 Lv1～Lv5、各類槽位幾個，是一張可以直接改數字的表。艦種也可以在編輯器裡新增、刪除。
  - 這張表是規則，標記是位置：設計裡各類標記的數量要和表一致。不一致時編輯器會標紅、顯示「還差 2 個副砲槽」，而且不能發佈。
  - 下面第三節的數字只是預設值，之後都在編輯器裡改。
- **槽位有編號，升級時沿用**：Lv1 的 3 號主砲槽到了 Lv2 還是 3 號，所以裝在上面的裝備不會掉。新等級只會多出新的槽，或移動舊的槽。
- **「放進遊戲」**：編輯器裡有一個「艦種」面板。
  - 你在面板裡建立艦種、指定 Lv1～Lv5 各用哪份設計，按「發佈」。
  - 發佈時產生遊戲用的模型：合併、減面、烤成一張貼圖。結果寫進 `models/戰艦組裝/hulls.json`。
  - **只有發佈過的艦種會出現在艦長模式。**
- 現有 5 種船（借用勢力船體的）也要在編輯器裡標槽位。編輯器要能載入勢力船體當底，例如帝國驅逐艦。

### 2. 裝備

| 類別 | 初版裝備（沿用現有模組） |
|---|---|
| 主砲 | 磁軌砲、重粒子砲、速射砲、光束砲（研發） |
| 副砲級 | 標準砲塔、重型砲塔、標準飛彈艙、重飛彈艙、蜂群飛彈艙 |
| 防空 | 防空砲（點防禦）、遠程防空砲 |
| 艦載機 | 護航機中隊（每槽 3 架，暫定） |
| 輔助 | 實體裝甲 大／中／小、能量護盾 大／中／小、超頻引擎 大／中／小 |

- **船的火力改成裝備加總**：艦種本身只有船體、護盾、速度、轉向和技能，武器全部來自裝備。
- **輔助裝備**：
  - 裝甲加船體，速度略降。
  - 護盾加護盾。
  - 超頻引擎加速度、加速度，船體略降。
  - 同類裝多個會疊加，但效果遞減（暫定第 2 個 ×0.8、第 3 個 ×0.6…）。
- **外觀**：每件裝備有自己的模型，裝在槽位的位置與朝向。
  - 武器用各勢力的武器模型，或戰艦建模零件庫的砲塔。
  - 輔助裝備用零件庫的元件：裝甲板、護盾發生器、推進器。
  - 所以同一艦種、不同裝備，外觀就不一樣。
- **Mk** 記在每件裝備上；改裝時換掉裝備，Mk 就回到 I（跟現在一樣）。
- **熟練度**照舊「每種裝備一條」。

### 3. 戰鬥

- 主砲：所有主砲都朝準心轉，射界內的一起開火。每門有自己的射界（標記上設定）和裝填時間。
- 副砲、防空砲：自動開火，跟現在的砲塔、點防禦一樣，只是數量和位置依槽位。
- 飛彈艙：每個飛彈艙有自己的彈量，鎖定後一起發射。
- 艦載機：所有艦載機槽的架數加總。
- 勝率、存活率的公式（capOdds）要重新校正，因為火力改成看裝備了。

## 三、新艦種（初稿，數字都可以改）

槽位數寫成「Lv1 → Lv5」，這只是預設值。每一級的實際數字、各艦種的數值，都在編輯器的艦種面板裡新增或修改。

| 艦種 | 模型 | 定位 | 主砲 | 副砲 | 防空 | 艦載機 | 輔助 |
|---|---|---|---|---|---|---|---|
| 雙叉戰艦 | 雙叉 1200m | 重砲：雙叉之間的大口徑主砲 | 1→3 | 2→4 | 2→4 | 0→1 | 1→2 |
| 三體戰艦 | 三體 1000m | 飛彈戰艦：浮筒上的發射艙 | 1→2 | 2→6 | 2→4 | 0 | 1→2 |
| 發射艦 | 發射艦 1200m | 航母：艦首發射口、兩舷機庫 | 0→1 | 1→3 | 2→4 | 1→3 | 1→2 |
| 新月戰艦 | 新月 1000m | 護盾／前衛：C 形環臂 | 1→2 | 2→4 | 2→3 | 0 | 2→3 |
| 運輸艦 | 運輸艦 1000m | 支援：大量輔助槽、維修 | 0→1 | 1→3 | 2→4 | 0→1 | 2→4 |
| 輕運輸艦 | 運輸艦 320m | 輕型護衛，入門艦 | 0→1 | 1→2 | 1→2 | 0 | 1→2 |

技能先沿用現有的五種（推進過載、護盾超載、維修光束、電子干擾、匿蹤），之後再加新的。

## 四、進度

### 第 1 步完成（2026-11-22）

- **資料**：表格都在 `caphulls.js` 的「槽位制度」一節。
  - `CAP_KIND`：槽位種類與能裝的東西。
  - `CAP_GEAR`：裝備。
  - `CAP_AUX_FAM`、`CAP_AUX_SIZE`：輔助裝備的效果與大中小。
  - `CAP_HULL_SLOTS`：每個艦種 Lv1～5 的槽位數。
- **船的記錄**：`c.eq = { main0: { g: 'std', mk: 1 }, sec0: …, aux0: { g: '', mk: 1 } }`。
  - 槽位編號升級時沿用；升級多開的槽是空的。
- **數值**：`capHullEq` 照裝備算。
  - **原廠 Lv1 船的數值和以前完全一樣**，同配置對打勝率 50%。
  - 多門主砲先合成一門（傷害相加），戰鬥第 4 步再分開。
  - 主砲槽都沒裝主砲時，這艘船不開主砲。
- **舊存檔換算**：
  - 主砲模組、副砲模組、飛彈模組換成對應的裝備，防禦和引擎模組換成輔助裝備。Mk 跟著換過去。
  - 原廠防禦、引擎升過 Mk 的，換成小型裝甲、小型超頻引擎。
  - 「機庫」在沒有艦載機槽的船上裝不了，拆下來退 200 資金。
  - 藍圖改用裝備系列當鍵；排隊中的改裝也一起換算。
- **研發與藍圖**：
  - 光束砲、反應裝甲、仿製（重粒子砲、速射砲、衝刺超頻引擎）照舊。
  - 聯盟的「機庫」改成艦載機槽的「攔截機中隊」（4 架）。
- **AI**：
  - 陣營的 Mk 套在每件裝備上。
  - Mk II 起，輔助槽補中型裝甲、中型護盾，代替以前防禦槽 Mk 的加成。
  - 招牌裝備裝在能裝的槽位。
- **介面（暫時版，第 5 步會重做）**：
  - 船的資料：每個槽位一列。
  - 改裝：每個槽位一個下拉選單（只列能裝的，鎖住的寫原因）＋Mk 按鈕；價錢＝換上的裝備＋Mk。
- **驗證**：
  - `npm test` 9／9 通過。
  - `capcareer-run` 8 局 × 60 週沒有出錯，結果和改之前差不多。
  - 舊存檔換算、改裝畫面、AI 對 AI 戰鬥（2 門主砲的船、沒有主砲的船）都實際跑過。

## 五、開發順序（建議）

1. **資料與規則**
   - 槽位、裝備的表格，以及「艦種＋等級＋裝備 → 實際數值」的計算（取代 capHullMod）。
   - 舊存檔換算。
   - 現有 5 種船先用預設的槽位位置（從目前的武器掛點推出來）。
2. **編輯器：槽位模式**
   - 放置、拖曳槽位標記，設種類、朝向和射界；顯示每級的槽位表。
3. **編輯器：艦種面板與發佈**
   - 新增、刪除艦種，編各艦種的數值與 Lv1～Lv5 槽位表。
   - 指定 Lv1～Lv5 的設計，檢查標記數量和表一致。
   - 發佈時合併、減面、烤貼圖，寫入 hulls.json。
4. **戰鬥**
   - 艦長戰場用發佈的模型。
   - 裝備模型裝在槽位上。
   - 多主砲朝準心、各槽位的副砲與防空砲。
5. **改裝畫面**
   - 整修庫、改裝面板改成槽位：點槽位、選裝備。
6. **6 艘新艦種上線**
   - 數值、槽位表、發佈；校正勝率公式。

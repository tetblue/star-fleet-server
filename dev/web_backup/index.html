光束與護盾

主砲只能打船頭前方（±25～30°），射程最遠、最重；打小船較難命中
副砲前方＋兩側（±120°），射程中等；打中距離的戰艦，近距離有飛彈／艦載機時先打它們
防空全方向，射程短；優先鎖定飛彈，其次艦載機，都沒有才打戰艦。圓陣對空最好，變換陣型中下降
命中率距離越遠、目標越小、目標移動越快越難打中；星雲裡、被干擾時再下降。飛彈、艦載機攻擊船也有命中率（飛彈有導引，較準），沒中的飛彈會從旁邊掠過自爆
護盾光束、艦載機要先打光護盾才傷到船體；飛彈打在護盾上也會炸傷船體，護盾沒了直擊更痛。10 秒沒被打就慢慢回充
艦載機航母機庫依「編成」設定的比例裝四種：攔截機（守艦隊上空，打飛彈與艦載機）、攻擊機（掃射）、飛彈攻擊機（防空射程外放 2 枚飛彈後返航）、光束攻擊機（貼近照射持續光束，消耗護盾快、打穿後船體傷害高）。艦載機小而靈活，防空不容易打中，但攔截機打它們很準
側背打到敵人側面／背後，船體傷害 ×1.5／×1.75（護盾沒有方向）

操作難度

在「單人戰鬥」或編成畫面選擇。一般：可用 2D、3D 與指揮官模式，艦隊都在同一平面（不能升降）。進階：作戰中只能用 3D 與指揮官模式，艦隊可以上下移動。擬真：開戰直接上艦橋、作戰中不能離開指揮官模式（部署時仍可看 3D 全圖），艦隊可以上下移動，而且射線穿過「別支艦隊」的友軍時可能誤傷（同一支艦隊內不會）：別把艦隊排在另一支艦隊的正後方。回放不受限制。

作戰模式

主選單 →「單人戰鬥」→「訓練作戰」（隨機戰役、無限戰場流程相同）：讀作戰簡報（情報可能有誤或不完整）→ 用預算編成艦隊、指派指揮官 → 在橘色部署區用右鍵點擊放置艦隊（右鍵拖曳指定朝向，↺↻ 旋轉；左鍵點艦隊切換要放的那一支）→ 開戰。敵軍損失 75% 即潰走（勝利）；時間到依雙方損失比例判定。技能：按畫面下方按鈕或鍵 6／7／8（集中火力／鐵壁／突進），集中火力要再點一支敵方分艦隊。按 A 再左鍵點敵方分艦隊＝指定攻擊目標（不加傷害、沒有次數限制）。空白鍵暫停，＋／－ 調速度（×0.5～×8）。戰後可以觀看回放。

移動規則

指定朝向與目前朝向差 60° 以內：直接過去，邊走邊微調；目標在後方就倒退（半速），在側面 0.6 倍速。差 60°～120°：原地轉向，重排、移動、轉向同時進行。差 120° 以上：反向迴轉——窄的陣型（縱陣等）蛇行，艦首帶頭繞彎、後面沿同一條路跟上；寬的陣型（橫陣等）打散，每艘船各自繞弧線掉頭，到目的地重新組成陣型。可在測試場面板「反向迴轉」固定用其中一種；觸控可用「原地轉向」按鈕改成原地轉。迴轉途中下的變陣命令，會在迴轉完成後執行。

光束射程

光束在有效射程（預設 250）內全威力，之後隨距離線性衰減，到最大射程（預設 700）剩 25%，超過最大射程不開火。開戰時兩軍約相距 480，威力約六成；拉近距離才能打出全部火力。飛彈不受影響。左上角顯示兩軍光束目前的平均威力。

側面與背後

被攻擊的方向以目標艦當下的船頭判斷：前方 ±60° 是正面，船尾 ±60° 是背後，其餘是側面。側面、背後受擊的擊沉機率預設加倍（面板「戰況」可調）。分艦隊最近受到的攻擊有三成以上來自側背時，標籤會顯示紅字警示；左上角統計各方向被擊沉的艦數。下令前地面會顯示路線、到達位置和朝向箭頭。
